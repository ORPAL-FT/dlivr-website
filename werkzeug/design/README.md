`dlivr-hell.css` ist der helle Tokenadapter der Website und steht wortgleich am Anfang von
`css/style.css`. Die Tokenwerte selbst liegen nur im Design-System
(`DLIVR_DATAHOUSE/GEMEINSAM/design-system`, Repository `ORPAL-FT/design-system`);
`werkzeug/design-pruefen.py` liest sie von dort. Regelbasis 1.3.1: große Kennzahlen und
Abschnittstitel in Grundschrift; Monospace nur für kleine Kennungen bis 12 CSS-px.
Keine Werte aus Websites zurücklesen.
